# Project status / 项目状态

As of 2026-10-31, biological research and autonomous research runs have stopped at the owner's request. The repository remains available for inspecting and reproducing existing work. No new biological findings are announced by this consolidation.

截至 2026-10-31，已按所有者要求停止生物研究及自主研究任务。仓库继续保存已有工作，供查阅和复现；本次整合不构成新增生物学发现。

## Preserved scope

- The existing laboratory PR heads are retained through merge commits. Original source branches are kept; no upstream repository is merged or represented as accepting a contribution.
- Project code, certificates, licenses, and provenance remain with their packets. The [complete index](PROJECT_INDEX.md) lists all top-level project directories.
- The [consolidation manifest](CONSOLIDATION_2026-10-31.json) records the original laboratory PR numbers, source commits, and check counts at the integration snapshot. Those checks are computational evidence, not scientific peer review.
- Historical roadmaps and proposed work remain as records. They do not authorize further autonomous research.
- Private correspondence, process logs, failed exploratory work, and support/account information remain outside the tracked repository. Unpublished local candidates are not included.

## Interpretation

The retained packets include mathematical model results, software corrections, numerical audits, and benchmark analyses. Their individual READMEs state the relevant assumptions and limitations. Repository inclusion does not imply that a result is a new biological mechanism, that a new molecule has experimental validation, that an upstream patch has been accepted, or that priority has been established.

本仓库包含数学模型结果、软件修正、数值审计和评测分析。具体假设与限制以各项目 README 为准；归档与合并不等于发现新的生物机制、新分子经过实验验证、上游采纳或优先权成立。
