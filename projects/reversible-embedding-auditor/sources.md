# Primary sources and bounded status check

Ellen Baake, Michael Baake and Jeremy Sumner, *Embedding of reversible Markov matrices*, [arXiv:2511.22800v1](https://arxiv.org/html/2511.22800v1), 27 November 2025, Theorem 3.16. The introduction defines arbitrary embeddability using a Markov generator; Definition 3.8 and Lemma 3.10 treat the additional reversibility requirement separately. The target is precisely the stated implication (1)⇒(3). The inspected [arXiv history](https://arxiv.org/abs/2511.22800) lists v1. The current [official institutional PDF](https://www.sfb1283.uni-bielefeld.de/preprints/sfb25065.pdf), printed pages 12–13, contains the same theorem and deformation argument. Bounded title/identifier searches did not locate a correction or verified author code repository. This is not proof of absence.

Chen Jia, *A solution to the reversible embedding problem for finite Markov chains*, Stat. Probab. Lett. 116 (2016), 122–130, [arXiv:1605.03502](https://arxiv.org/abs/1605.03502), gives uniqueness and a criterion for a reversible generator. This note does not refute that result or conflate it with arbitrary generators.

M. Casanellas, J. Fernández-Sánchez and J. Roca-Lacostena, *An open set of 4×4 embeddable matrices whose principal logarithm is not a Markov generator*, Linear Multilinear Algebra 70 (2022), 3768–3779, [arXiv:2005.00821](https://arxiv.org/abs/2005.00821). Nonprincipal Markov generators are known. Its inspected Section 3/Remark 3.5 uses a nonreal eigenpair and discusses repeated-negative examples; these displayed cases differ from this symmetric positive-spectrum witness.

M. Casanellas, J. Fernández-Sánchez and J. Roca-Lacostena, *The embedding problem for Markov matrices*, [arXiv:2005.00818v2](https://arxiv.org/html/2005.00818v2), revised 22 June 2021. Definition 5.9, Theorem 5.11 and Corollary 5.14 already parametrize logarithms for a repeated real eigenvalue. The construction here uses known repeated-eigenspace machinery; it is not a new general parametrization.

Jordi Roca Lacostena, *The embedding problem for Markov matrices*, doctoral thesis, Universitat Politècnica de Catalunya (2021), [official repository record](https://hdl.handle.net/2117/349579), [official thesis PDF](https://upcommons.upc.edu/bitstream/handle/2117/349579/TJRL1de1.pdf?sequence=1). Fresh review retrieved the thesis after an initial access failure. The bounded inspection covered printed pages 80–85 (repeated-eigenspace logarithm parametrization), 99–106 (Kimura restrictions), and 125–138 (nonreal-spectrum nonprincipal examples). This establishes methodological overlap; no equivalent symmetric positive-spectrum witness was located in those portions. The entire thesis was not exhaustively audited. Historical priority remains unverified.

M. Baake and J. Sumner, *Embedding of Markov matrices for d≤4*, J. Math. Biol. 89:23 (2024), [DOI](https://doi.org/10.1007/s00285-024-02112-w), [arXiv:2311.02596](https://arxiv.org/abs/2311.02596). Low-dimensional/simple-spectrum criteria and inverse methods are prior work. The present input has a repeated positive eigenvalue. This is a theorem-specific correction candidate, not a new general embedding algorithm.
