| Meshkat–Sullivant–Eisenberg, arXiv:1410.8587v1, §5 Theorem 5.1, https://arxiv.org/html/1410.8587 | Starting with an identifiable cycle model, collocated root input/output retained, a model is identifiable if every leak is an input/output compartment. With one input and root observed this gives B⊆O, a sufficient case covered here by singleton linkage. The proposed criterion also permits unobserved leaks and gives a necessary condition plus an exact rank/ambiguity formula. The theorem is explicitly credited; it is not advertised as new. |
| Bortner–Meshkat, arXiv:2010.07203v2, Theorem 3.19, Theorem 4.1, Corollaries 4.2/4.3, §9, https://arxiv.org/html/2010.07203 | Results connect path/cycle identifiability, leak removal, leak addition and special Leak=In∪Out placements. Theorem 6.1 supplies the already-known counting obstruction L>|In∪Out|; here topology sharpens it. |
