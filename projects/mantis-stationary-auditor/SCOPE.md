# Contract, repair and limits

For `A <-> B` at unit rates, total A+B=2 and molecule scaling N_A V=1, the product weights of `(0,2),(1,1),(2,0)` are `1/2,1,1/2`. The old method evaluates the outside point `(0,0)` as `1/2` instead of zero. For `2A <-> 2B` from `(2,0)`, the reachable class contains only the endpoints; its exact CTMC has both jump rates equal to 2. The endpoint probabilities are exactly `1/2,1/2`. The old three-state law `1/4,1/2,1/4` has exact residual pi Q=0, so it remains a stationary mixture, but it is the wrong law conditional on that initial class.

The candidate traverses enabled reactions only after the existing enumeration has established a complete finite conservation class. Enabling checks the full reactant complex, including dynamic catalysts, and positive static rate / chemostat factors. It reuses Mantis's FSP traversal, restricts product weights to the reachable class, rejects incomplete/inconsistent traversal, and caches support membership so valid integer queries outside it return exactly zero. A positive weakly reversible complex cycle gives return paths while preserving surplus molecules, establishing communication of the reached closed class under the existing hypotheses. This standard graph/CRNT argument is not a new theorem.

Dynamic `A + 2C <-> B + 2C` with C=1 has a positive continuous equilibrium but no enabled stochastic reaction. Its initial class is singleton. A positive chemostatted C is instead a fixed concentration factor and must not be treated as an inventory threshold. Both controls are tested. The absent-C=0 example is helper-only: the public API's existing positive-equilibrium requirement is retained.

Exact parts: integer support and rational CTMC stationary reference laws. Floating parts: existing library equilibrium and normalized log weights, compared at declared tolerances `1e-10` (helper/product law) and `1e-7` (public API). The 352 owner cases and 1,077 fresh review cases are bounded, partly overlapping coverage; they are not independent experimental observations or 1,434 full public-API runs. Only five owner oracle cases exercise the complete public stationary-distribution constructor; two additional baseline/candidate API comparisons expose the original defects.

Not covered: infinite initial components; unconditioned Poisson-law uniqueness; all fractional/invalid inputs; floating equilibrium accuracy; boundary classes lacking a strictly positive initial-class equilibrium. Existing unconditioned product-Poisson invariant laws and approximation fallback APIs remain unchanged. There is no GPU, wet experiment, new biological result, new ACK theorem, first-discovery claim, trusted-runner certificate, or external human validation.
