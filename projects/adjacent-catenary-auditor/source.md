# Source question and primary references

Original question, verbatim: “For a four-compartment bidirected path, input1/output2 and one leak, characterize all positive parameter points where the coefficient Jacobian loses rank.”

This investigation covers all fixed leak locations ell=1,2,3,4.

Primary starting sources inspected 2026-10-26: Ahmed et al., Identifiability of directed-cycle and catenary linear compartmental models, arXiv:2412.05283v3, SIADS 25(1), 304–350 (2026), DOI 10.1137/25M1728636, https://arxiv.org/html/2412.05283v3, Theorem5.1 and Discussion; Meshkat–Shiu review arXiv:2507.04496v1, https://arxiv.org/html/2507.04496v1; Gross–Meshkat–Shiu arXiv:1709.10013v3, https://arxiv.org/html/1709.10013, §§5.3/5.4/7; Alper Ferudun, An Exact Singular-Locus Formula for Rooted-Tree Compartmental Models, 15October2026, https://eulersolve.org/papers/owr-11695865-007/.

No original source explicitly labels this exact adjacent noncollocated question as an open conjecture. It is a new restricted question within the stated singular-locus direction. Priority remains unverified.
