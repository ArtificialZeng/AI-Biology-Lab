# Exact question and scope

Fix arbitrary a,b,c,d,e,f>0. For the exact source model in source.md and each
x>0, establish existence and uniqueness of a nonnegative steady state with
A+B+C=1. Classify the number and type of finite-input critical points of the
steady response B(x), including the equality case in the rate threshold.

The result is a full-six-rate statement for this motif: there is one interior
steady state, smooth in x; C decreases strictly; B is strictly increasing iff
ad<=(a+c)(b+c), and otherwise has one nondegenerate global maximum. The proof
gives its exact state, input and height. Since x=exp(F_a/2), criticality has the
same classification in F_a.

Inputs zero and infinity are endpoint limits, not finite-input critical points.
The classification includes rates arbitrarily near the threshold; no symmetry
or finite parameter box is assumed. The accompanying numerical tests are
nonexhaustive checks of implementation, and do not supply the quantified proof.
The broader source question remains unresolved.
