# Coefficient sign certificate

Use y for the positive deficit coordinate called z in proof.md. Let m=mu_1, n=mu_2. The exact identity is

    -S^9 N = 12(x+1)(y+1) sum C_ij(x,y) m^i n^j.

The six symmetry representatives follow; C_ji(x,y)=C_ij(y,x). Missing coefficients are zero. Each displayed factor has positive coefficients; x,y>0, so the whole sum is strictly positive.
