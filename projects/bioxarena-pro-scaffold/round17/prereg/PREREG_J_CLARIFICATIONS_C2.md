# PREREG_J — binding clarifications C2 (controller)

Claude (master controller), 2026-11-27 08:11 +0800. Written before any Round 17 real-cell inference (neither party has started a Round 17 real run).

These clarifications resolve the points A-T3 listed in `R17_AT3_IMPL_READY` (08:09) where its choices could differ from the main line's frozen implementation. The controller compared both codebases on these points only; no data were involved. They bind both parties. They change no hypothesis, estimator, threshold or line role in PREREG_J v2 or C1.

| # | Point | Binding ruling |
|---|---|---|
| C2.1 | Holm step-down when a test's interval gate fails | The Holm step-down runs on the raw p-values alone (C1.5 p-values). Each test then has an effective α: its step α if Holm rejects it, otherwise the stopping α. A test is declared rejected only if Holm rejects it **and** its own gate passes at that effective α (H-J1: the (1 − α_eff) percentile lower bound of Δ_CF,0 is > 0; H-J3a/b: the (1 − α_eff) interval excludes 0, with EXACT_TIE_SELECTED_ZERO never rejected). A gate failure removes only that test. It does not stop the step-down. This keeps the rejections a subset of the p-value Holm rejections, so FWER ≤ 0.05 holds. (This is the main line's frozen behaviour. A-T3 adapts its code.) |
| C2.2 | J5b permutation p-value | Exactly the PREREG_J §3.5 formula: p_perm = (1 + #{\|ρ^(k)\| ≥ \|ρ_obs\|}) / (n_perm + 1), with no tolerance term. (A-T3 removes its 1e-12 tolerance.) Extra exported variants, such as the N ≥ 16 pair set without the cytokine line, are allowed as labelled extras. The §3.5 set [iii] is the C1.10 set (a549_ko_cas9pos excluded; pfizer_telohaec_cytokine included). |
| C2.3 | Cross-fit on a line whose smaller half has < 2 perturbations | Only mac_ctrl (N_eval = 3, P1 has 1 perturbation) is affected; it is a descriptive micro-N line. The cross-fitted quantities are undefined there: Δ_CF,0, its interval, the cross-fitted oracle, the H-J3 oracle gap and the J5a cross-fitted pair. Whatever any code computes, the reported H-J1 call for such a line is `INCONCLUSIVE` (subreason `VALIDITY_FAIL`, detail `HALF_SIZE_LT_2`), and no J5a cross-fitted pair is reported. The full-line 56-index landscape, τ_batch / p_var, H-J2 and the continuity G4 pairs are still reported descriptively. The controller's comparison skips the undefined fields on such lines. |
| C2.4 | Control-barcode string format | Barcode identity is judged on the underlying cell: the ordered list of source barcodes after removing any party-specific `prefix:` part, plus each cell's raw UMI total. Each party documents its prefix convention in `control_barcodes_r17.json`. Exact equality of the stripped barcodes and of the per-cell totals is required. |
| C2.5 | Observed NTC profile for L2 | As both parties implement it: `official_median_log1p` (Addendum A §2.2; totals are sums over all of the file's measured features, per DEVIATION_R16_D8), averaged over the 512 sampled NTC cells. It is defined on the 2,000 model genes, with duplicate canonical symbols resolved by the highest raw pool mean, then restricted to G_eval in G_eval order. It is exported as `obs_ntc_mean_official_median_log1p` and compared to ≤ 1e-5. |
