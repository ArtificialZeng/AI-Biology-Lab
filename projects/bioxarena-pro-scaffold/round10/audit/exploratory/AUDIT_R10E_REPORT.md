# Round 10-E Independent Post-Hoc Baseline Ablation Audit (`A-T3`)

> **重要声明（事后探索性分析 / Post Hoc Exploratory）：** 本文全部结果均为事后探索性消融审计（`R10-E`），非第十轮预注册确认性检验；主要科学判定仍以 `PREREG_C` 确认性结论为准（`H-C1 2/2`, `H-C2 0/2 -> 未确认`, `H-C3 2/2 PASS`）。

- **Parameters:** `n_boot = 4000`, `seed = 20261122`, two-sided Bonferroni `97.5%` CIs (`[1.25%, 98.75%]`), zero frozen manifest edits.
- **Predictors Verified:** `FCT` (real target baseline $\mu_t$), `E1` (constant gene-invariant median $c = \operatorname{median}(\mu_t)$), `E6` ($\ln(\overline{\mathrm{FC}})$, $c\to\infty$ limit), `E7` ($\overline{\mathrm{FC}} - 1$, $c\to 0^+$ limit), plus paired `FCT - E1` on identical bootstrap draws.

- **交叉核对明细文件：** [`cross_check_r10e.json`](cross_check_r10e.json)（对比 `round10/exploratory/baseline_ablation_metrics.csv` 与 `round10/exploratory/baseline_ablation_paired_fct_vs_e1.csv`）。
- **科学解读（事后探索性 / post hoc）：**
  1. 在 **`resp_top50`**（按 $|\Delta^{\mathrm{obs}}|$ 选取 Top-50 强响应基因）下，单标量基因无关常数基线 `E1` 复现了真实 `FCT` 去幅度分数的 **`86.4%–115.5%`**，且配对差 `FCT - E1` 的 `97.5% CI` 在 `dld1`（`-0.0166 [-0.0708, +0.0396]`）、`cd4t_rest`（`+0.0065 [-0.0136, +0.0270]`）与 `nadig_jurkat`（`-0.0162 [-0.0326, +0.0006]`）上均跨越 `0`；`E6`（`ln FC_bar`）给出相近甚至更高分数，说明在该强响应子集上，核心增益主要源于跨源几何均值 Fold-Change 空间平均与全局 `log1p` 压缩（`E1`/`E6`），而非目标细胞系特异性的基因间基线差异。
  2. 在无 top-50 选择的 **`all_nontarget` (`S6`)** 全转录组掩码下，`E1`/`E6`/`E7` 全部崩溃至近零或负相关（`-0.0782` 至 `+0.0437`），而真实 `FCT` 保持稳健正值（`+0.0556` 至 `+0.1848`），`5/5` 细胞系的配对差 `FCT - E1` `97.5% CI` 全部严格大于 `0`（如 `dld1 +0.1969 [+0.1673, +0.2253]`、`cd4t_rest +0.0426 [+0.0248, +0.0605]`），表明真实目标线基线 $\mu_t$ 在全基因尺度上对低表达非响应基因的非线性压低作用显著存在，但这一差异被 `resp_top50` 的高响应基因筛选掩盖。
