# Scout S2 筛查报告：提前公开押题（前瞻性预测）

## 1. 方向概述

当前“虚拟细胞”和单细胞扰动预测面临的核心痛点，是绝大多数模型仅在已公开的追溯性划分上评估，既无法排除超参数或文献泄露，也缺少像 CASP 那样在实验表型揭晓前先公开发布加密时间戳预测的前瞻盲测（Gillenwater & Greene, 2026）。围绕 2026-11-21 起未来 3 个月（至 2027-02-21 附近）可能公开的新增单细胞扰动数据集，本轮全面排查了大规模联盟发布周期（MorPhiC、Arc VCC 2026、VBI/CZI、Tahoe、Helmholtz+Parse）、商业联盟（Cascade、Illumina BCA）、新近挑战赛（NeurIPS Virtual Embryo Challenge）与 2026 年 5–11 月 bioRxiv 预印本及对应 GEO/IGVF 状态。实证结果显示：**当前并不存在“既明确锁定唯一未来测试集与日期、又可在无账号注册前提下直接获取精确测试输入”的完美 0 风险标的**；最可行且合规的唯一公开候选为 **MorPhiC Data Release 5.0 待发布基因集（条件推进）**，其余高关注竞争数据集因账号注册条款阻塞、真实 GT 永不公开、商业授权或等待期超 3 个月/不确定而被条件待定或淘汰。

## 3. 排名前二候选详细评估

### 候选 1（Rank 1 · 条件推进）：MorPhiC Consortium Data Release 5.0 未发布 KO 基因集

1. **S2 五项专项核查**
   - **预期公开日期与权威依据**：`MorPhiC Data Release and Use Policy v1.1` 明确规定：*“Production data and associated metadata will be shared with the public on a 6-months cycle basis”*（[Policy URL](https://morphic.bio/docs/policies/data-release-and-use-policy)）。历史正式发布节奏可直接在官网查证：[R1.0](https://morphic.bio/release/1.0)（2025-01）、[R2.0](https://morphic.bio/release/2.0)（2025-09）、[R3.0](https://morphic.bio/release/3.0)（2026-04-10）、[R4.0](https://morphic.bio/release)（2026-08-10）。按 R4.0（2026-08-10）起算，R4 间隔曾缩短至 4 个月（2026-12），按政策 6 个月周期则为 **2027-02-10**，正好落在 **2026-11-21 起 3 个月内（≤ 2027-02-21）**。*不利信息提示*：MorPhiC 官网并无 R5.0 倒计时承诺，且 R1→R2→R3 曾间隔 7–8 个月，存在顺延至 2027 年 3–4 月的风险。
   - **许可证**：全量开放获取数据采用 **CC BY 4.0**（[morphic.bio/docs/data-license](https://morphic.bio/docs/data-license)），免账号下载，仅要求引用 `Adli et al., Nature (2025)`、对应数据版本号及 GEO/ENA 编号。
   - **实验公开前能否取得输入（基因表、control 细胞、扰动清单）**：
     - **基因轴（GRCh38 / GENCODE v44）**：已完全公开在 R4.0 `processed_v1` counts（`.h5ad`）与 224 个 `UCSF_Perturbseq` DE TSV 中。
     - **Control 细胞**：① **H1 hESC 系**：`MSKCC_Pooled_scRNAseq_40KO` 与 `30KO`/`30KO_GEMX` 明确包含约 6% 混入 WT 对照细胞（`H1` ES 阶段及 Definitive Endoderm Day 3 等阶段，`.h5ad` 可于 EBI FTP 直接下载）；② **KOLF2.2J hiPSC 系**：`UCSF_Perturbseq` 含有全套未靶向对照（NTC，iPSC 与 Day 8 EB 共 16 个 `.h5ad`）且 `JAX_scRNAseq01` 提供皮层脑类器官 Day 7/8/9 WT 对照 `.h5ad`（180–265 MB）。
     - **未发布扰动基因清单**：官网公开清单 `https://morphic.bio/cell_lines.tsv`（393 行）经大小写归一后共 **320 个唯一已建系基因**（比对 `integrated-read-api` 中已发布的 366 个基因），**有 172 个已建成敲除细胞系的基因在 R1–R4 中尚未发布任何组学数据**：
       - **MSKCC `H1` 多克隆 KI-KO 库**（共 145 个基因）：R1/R2/R4 已释放 84 个（含大小写归一化 `Rb1`/`RB1`），**尚有 78 个未见于 MSKCC scRNA-seq**（其中 63 个在全联盟 4 个中心均 0 数据；按 `SET` 拆分：`Yr 1` 缺 3 个、`Yr 2` 缺 27 个、`Yr 3` 缺 49 个）。且 R4.0 `40KO` / `30KO` 证实 MSKCC 正稳定用同一套 `H1 LARRY + PolyIII` 混合分化（ES + DE Day 3）批量产单细胞转录组。
       - **JAX `KOLF2.2J` 克隆 KO 库**（共 199 个基因）：已释 78 个，**尚有 121 个未在 JAX 发布**（含 34 个标记为 `MorPhiC Yr 5` 的胚胎外/发育转录因子与 87 个常规建系基因；109 个全联盟 0 数据）。
     - **必须如实指出的输入缺口**：MorPhiC **不会在 R5.0 上线前公告“R5.0 精准包含 172 个待测基因中的哪几批、做的是单细胞还是 bulk、采的是第几天（ES/DE/Day 7–9/EB）”**。因此不能押“单基因单文件必中”，而必须以 **全量 78 个待发 MSKCC H1 KO（覆盖 H1 ES 与 H1 DE 两上下文）+ 121 个待发 JAX KOLF2.2J KO（覆盖 iPSC/EB/CBO 上下文）** 构建确定性批量预测矩阵。
   - **SHA-256 上链时间戳可行性**：完全可行。本地预测产物压缩为标准化表格（基因 $\times$ 待预测扰动 $\times$ 上下文 `log2FC_pred`、`p_adj_pred`、`mean_shift` 与子采样预测 `.h5ad`），在 R5.0 释放前连同脚本哈希（`shasum -a 256`）推送至公开 GitHub 提交记录即可锁定先验时间戳。
   - **先例查新**：`Adli et al. (2025)` 为联盟综述，`McKeever et al. (2026-10-19)`（`10.64898/2026.10.16.759756`）为 R1–R4 已有数据的整合软件，`MORPH`（`He et al., 2026`）名字相近但与 MorPhiC 无关。**在我们检索的范围内未见**针对 MorPhiC 后续数据释放的预注册或 SHA-256 押题工作。

2. **具体科学问题**
   > **问题**：基于已有 CRISPRi（`UCSF_Perturbseq01` KOLF2.2J 224 基因）与基因敲除（`MSKCC_30KO/40KO` H1 70+ 基因、`JAX_scRNAseq01`）训练的单细胞扰动预测模型（线性基线、平均效应与表征迁移模型），在严格零偷看前提下提前对 `cell_lines.tsv` 中尚未公开的 **MorPhiC 已建系 KO 基因（重点 `MSKCC H1` 78 个未发布基因及 `JAX KOLF2.2J` 121 个未发布基因）** 生成转录组扰动响应预测；当 R5.0 发布后，与同细胞系历史观察基因分布或仅靠跨细胞系迁移相比，现有方法能否预测出跨多能干（ES/iPSC）至早期分化谱系（DE/EB/类器官）的真实敲除下游方向与基因特异性变化？

3. **预注册的成功判据**（完全由 R5.0 上线后 `MorPhiC` 官方发布或统一 `DESeq2/Wilcoxon` 差异表达真值判定，严禁自定义指标）
   - 若 R5.0 公开新批次 `MSKCC H1 ES/DE scRNA-seq` 或 `JAX/UCSF KOLF2.2J scRNA-seq/RNA-seq`，在预预测清单与 R5.0 实际新增 `gene × context` 交集上：
     1. **方向保真与全基因排序（主指标）**：全转录组与 Top-200 高变差异基因上的 $\Delta\log_2\text{FC}$ Pearson $r$ 与 Cosine 相似度显著高于“零变化（no-change）”、“训练均值效应（mean-perturbation baseline）”与“同源 CRISPRi 原始未校正迁移”，满足 $\Delta r \ge +0.05$（且配对 Wilcoxon/permutation $p < 0.01$）。
     2. **DE 基因集合召回**：显著 DE 基因（官方 $|\log_2\text{FC}| > 0.5, \text{FDR} < 0.05$）排序 AUPRC 显著高于随机基因背景与扰动强度无关基线（`ImmunoTwin` 所警示的“generic perturbation strength”混杂基线）。
     3. **负对照门控**：R4.0/历史已标注 `not_evaluable` 的低表达/无靶向效应基因不应产出高假阳性 DE 数量（对齐 VCC 2026 揭示的过度报错缺陷）。

4. **失败时能写成什么结果（可发表的负面结果与失效机制拆解）**
   - 即便前瞻预测未打败平均效应基线，仍可在一次完全不可质疑的时间戳审计下精准解剖以下三类高价值生物学/方法学失效机制：
     1. **CRISPRi 抑制 vs 工程化纯合/多克隆 KO（PTC / Cassette KI-KO）的机制鸿沟**：同源基因在 `UCSF KOLF2.2J CRISPRi` 与 `MSKCC/JAX KO` 之间响应相关性究竟有多少被无义介导衰减（NMD）与长期建系代偿抵消。
     2. **胚层分化时间依赖（`ES` → `DE Day 3` → `EB Day 8`）的上下文覆盖失效**：如靶向基因在 `iPSC` 不表达、仅在定型内胚层启动（`UCSF_Perturbseq` 中大量标为 `iPSC_not_evaluable` 却在 `EBs` 显著），静态控制细胞先验是否无法外推谱系唤醒。
     3. **多批次/微扰动量级效应 vs 模型复杂度假优势**，与 `Kawsar et al. (2026)`、`Shoeibi & Yousefi (2026)` 构成前瞻版正交实证。
