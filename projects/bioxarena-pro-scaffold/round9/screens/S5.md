# S5 选题筛查与查新报告：组合扰动 / 遗传互作预测

## 1. 方向概述

组合扰动与遗传互作（GI / 上位性）预测旨在仅凭单基因扰动数据及有限已知组合，外推双基因或多基因协同扰动的转录组或适应度结果。2025–2026 年多项顶刊基准测试与预印本已确认：在单细胞系内全表达重构任务上，深度学习模型难以稳定超越简单加性/线性基线，且残差流匹配等模型常在无交互处产生“幻觉”或仅捕获跨扰动共享偏移。围绕本组已建立的**跨细胞系核方法（S5 / HybridTOM）**、**秩-1 PC1 轴分解**与 **Miller DRF 校准框架**，本报告筛选出 3 个具备外部公开组合数据检验且检索范围内未见直接重名的可推进子问题，并淘汰 2 个已被覆盖或统计功效不足的候选。

## 3. 排名前 2 候选深度方案（及第 3 候选摘要）

### 排名 #1：C1 — 跨细胞系双基因遗传互作保守与重连预测（单基因 Perturb-seq S5 核迁移）

1. **具体科学问题**：
   当源细胞系 $A$ 已测得部分双基因遗传互作矩阵 $\Gamma^{(A)}$（如 Horlbeck 2018 K562 472×472 GI 矩阵，或 `sci-Plex-GxE` 胶质瘤系 A172 的 gene×drug 交互矩阵），而目标细胞系 $B$（Jurkat，或 T98G/U87MG）仅测得单基因 Perturb-seq 转录组图谱（如 Nadig 2025 Jurkat CRISPRi，或目标系单药/单基因扰动）时，能否利用**跨细胞系单基因核方法（S5：HybridTOM + GeneSlope-CosKRR）**与 **PC1 主轴分解**，把基因-基因功能协同图从细胞系 $A$ 迁移到细胞系 $B$，从而超越“直接复制源系交互（raw-copy）”与静态知识图基线，精准预测目标细胞系 $B$ 中**发生重连（rewiring）的细胞系特异性双基因上位性**？
2. **本组方法映射（S5 + PC1 可检验预测）**：
   - 将双基因交互矩阵分解为 **PC1 全局本质性/生长轴投影**（预测跨系保守的泛细胞系核心互作）与 **S5 跨系核迁移后的离轴基因模块交互矩阵**（利用 $K_{\mathrm{HybridTOM}}^{(B)}$ 与 S5 翻译后的基因协同度偏移 $\Delta K_{ij} = K_{ij}^{(B)} - \hat{K}_{ij}^{(A\to B)}$ 预测哪对基因会在 $B$ 系产生新的合成致死或缓冲重连）。
   - **直接给出别人没有的可检验预测**：在 Horlbeck K562↔Jurkat 共有基因对中，预测跨系单基因 HybridTOM 邻域重组程度 $\Delta K_{ij}$ 越大的基因对，其实验测得的跨系 GI 差值 $|\gamma_{\mathrm{Jurkat}}(i,j) - \gamma_{\mathrm{K562}}(i,j)|$ 显著更大（且定向符号可预测）。
3. **预注册的成功判据（Pre-registered Gates）**：
   - **前置功率门控（硬熔断）**：先锁定 Horlbeck 472 基因与 Replogle K562 / Nadig Jurkat 可重复单基因扰动交集，需满足共享靶基因数 $N_{\mathrm{shared}} \ge 80$ 且涵盖可验证双基因对 $M_{\mathrm{pairs}} \ge 1{,}000$（若不足则立即熔断转入 `GSE225775` 三系 G×E 同模态主线）。
   - **主要判据 H1（重连预测超越直接复制）**：在目标系留出对（`Seen1` 与 `Seen0` 分别检验，4,000 次基因级配对自助法），S5 跨系核模型预测的目标系 GI 分数 $\hat{\gamma}_B$ 在**强重连基因对子集**（$|\gamma_B - \gamma_A|$ 居前 20%）上显著超越源系直接复制（raw-copy $\hat{\gamma}_B = \gamma_A$）与线性单系基线（连续 8/10 折或整体 95% CI 严格 > 0），且重连差值 $\Delta\gamma = \gamma_B - \gamma_A$ 的预测相关性 $r > 0$（BH FDR $< 0.05$）。
   - **主要判据 H2（`GSE225775` 三系 G×E 同模态迁移）**：在 A172/T98G/U87MG 留一细胞系检验中，S5 跨系核对非加性 G×E 残差的 $\mathrm{disc}_{\mathrm{raw}}$ 与 $v_5$ 在至少 2/3 目标系上显著超越源系直接复制（raw-copy）、shifted-control 基线与未迁移单系线性模型（95% CI > 0）。
4. **失败时能写成什么结果**：
   - 若跨系单基因转录组核重排（$\Delta K_{ij}$）无法显著预测 Horlbeck 适应度 GI 重连（或发现 K562↔Jurkat 交互重连与单基因转录组相似度变化解耦），可定量界定“单基因转录组扰动图谱对双基因生长上位性重连的预测上限与跨模态信息瓶颈”，对比 `GSE225775` 同模态转录组 G×E 成功与跨模态（转录组→适应度）失效之间的清晰边界，仍具高价值方法学论文发表潜力（类似本组 Preprint v2.1 的 DRF 边界结论）。
5. **需要的数据（来源、许可证、大小）**：
   - **Horlbeck et al. (2018) K562 & Jurkat GI 图谱**：Mendeley Data `doi:10.17632/rdzk59n6j4.1`（DataCite API 核实许可证为 `CC BY 4.0`；注：Mendeley API 未返回文件字节大小字段，需攻题阶段直接下载确认，但文本型 472×472 矩阵通常数十至百余 MB 级）。
   - **Replogle et al. (2022) K562 & RPE1 单基因 CRISPRi**：Figshare+ `doi:10.25452/figshare.plus.20029387`（Figshare API 核实许可证 `CC BY 4.0`；`K562_gwps_normalized_bulk_01.h5ad` 为 `374.59 MB`，`K562_essential_raw_bulk_01.h5ad` 为 `79.77 MB`）。
   - **Nadig et al. (2025) Jurkat & HepG2 单基因 CRISPRi**：NCBI GEO `GSE264667`（NCBI 公开数据，仓库预印本已核验本地处理链路，无需重复下大文件）。
   - **McFaline-Figueroa et al. (2024) `sci-Plex-GxE`（A172 / T98G / U87MG gene×drug）**：NCBI GEO `GSE225775`（公开访问；大小需攻题首日下载前 `curl -sI` 确认 $< 1\ \mathrm{GB}$）。
   - **辅助多系合成致死验证**：`SCHEMATIC`（Fong et al. 2024, Zenodo `13864661`，API 核实 `cc-by-4.0`，`SCHEMATIC_240930.zip` **1.22 MB**）；`In4mer`（Esmaeili Anvar et al. 2024, Figshare `24243832`，API 核实 `CC BY 4.0`，总计 **49.23 MB**）。

### 排名 #2：C2 — 组合扰动非加性上位性残差（$I_{AB}$）的秩-1 PC1 轴分解与 Split-Half DRF 校准检验

1. **具体科学问题**：
   2025–2026 年文献出现严重方法学分歧：`Ahlmann-Eltze (2025)`、`Gao (2026)` 与 `Gijsen (2026)` 指出组合扰动神经网络并不稳定战胜加性基线且易幻觉出虚假交互；而 `SynGeneFlow (2026-10)` 与 `ReliFlow (2026-11)` 却报告高达 `0.573`–`0.638` 的非加性残差相关性（甚至 `GEARS` 达 `0.482`）。是否存在一个此前未被隔离的代数混淆因子——即原始交互残差 $I_{AB} = \delta_{AB} - (\delta_A + \delta_B)$ **重复减去了单扰动共享的 Systema 中心偏移 $\mathbf{b}$ 与主轴 PC1 饱和缓冲模式**——使得“全局收缩/缓冲”模型在未学会基因对特异性上位性的情况下获得虚高 `Resid. r`？在 **Miller DRF 重复控制校准**与 **秩-1 PC1 正交分解**下，哪些指标真正测量了基因对特异性上位性（$I_{AB}^\perp$），且双线性核方法（HybridTOM Bilinear Kernel）或已有深度模型能否超越 **PC1 阻尼加性零模型**？
2. **本组方法映射（PC1 分解 + DRF + HybridTOM 双线性核）**：
   - 构造显式无泄露对比基线 **PC1-Damped Additive Null**：仅在训练集单扰动和训练组合对上拟合残差均值偏移 $\hat{\mathbf{b}}_{\mathrm{int}}$ 与主奇异向量 $\mathbf{a}_1$（PC1），对测试对 $(A,B)$ 预测 $\hat{\delta}_{AB}^{\mathrm{PC1}} = \delta_A + \delta_B - \hat{\mathbf{b}}_{\mathrm{int}} - \hat{\lambda}\,\Pi_{\mathbf{a}_1}(\delta_A + \delta_B)$。
   - 借鉴 Miller et al. (*Nat. Biotechnol.* 2026) 构造 **交互残差专用 DRF 校准（$\mathrm{DRF}_{\mathrm{raw}}(I_{AB})$ 与 $\mathrm{DRF}_{\mathrm{raw}}(I_{AB}^\perp)$）**：在 Norman 2019、Wessels 2023（天生包含每靶点双独立 gRNA 技术重复 + 单细胞 split-half！）与 Joung 2023 上，用独立细胞/gRNA 半拆分重复的交互残差作为正控制 $m_{\mathrm{pos}}$，用加性零模型与 PC1 阻尼零模型作为负控制 $m_{\mathrm{neg}}$。
   - 测试 **HybridTOM 双线性交互核**（在正交子空间 $I_{AB}^\perp$ 上学习由基因功能核 $K_{\mathrm{HybridTOM}}$ 诱导的低秩对称双线性张量交互）。
3. **预注册的成功判据（Pre-registered Gates）**：
   - **机制假说 H1（PC1 解释既有残差相关虚高）**：在 Norman 2019 与 Wessels 2023 上，用仅含秩-1 $\hat{\mathbf{b}}_{\mathrm{int}} + \hat{\lambda}\,\Pi_{\mathbf{a}_1}$ 的**零非加性交互基因参数**的 PC1 阻尼加性零模型即可解释 GEARS / 公开流模型在原始 `Resid. r` 上 $\ge 50\%$ 的得分；移出 $\mathrm{span}\{\mathbf{1}, \hat{\mathbf{b}}_{\mathrm{int}}, \mathbf{a}_1\}$ 后，既有基线在正交残差相关 $r_\perp$ 上大幅坍塌（衰减 $\ge 50\%$ 或接近 0）。
   - **校准判据 H2（交互残差 DRF 分层）**：定量测定 $\mathrm{DRF}_{\mathrm{raw}}(I_{AB})$ 与 $\mathrm{DRF}_{\mathrm{raw}}(I_{AB}^\perp)$，证明原始 `Resid. r` 与交互 `MSE` 校准度失真，而基于交互残差的 `disc_raw` / `DE50_sign` 具高 DRF（预期 $\ge 0.70$，以实验观测为准）。
   - **方法假说 H3（核方法或深度模型真上位性检验）**：在 $\mathrm{DRF}_{\mathrm{raw}} \ge 0.50$ 的高校准指标上，比较 HybridTOM 双线性核、scGPT 交互探针、GEARS、CPA 与 PC1 阻尼零模型（10 折交叉验证，4,000 次配对自助法 CI）。
4. **失败时能写成什么结果**：
   - 即使所有模型（包括本组 HybridTOM 双线性核）在去除了中心偏移与 PC1 饱和阻尼后的正交上位性空间 $I_{AB}^\perp$ 上均**无法显著击败零交互或 PC1 阻尼零模型**，只要 Split-half 正控制显示 $\mathrm{DRF}_{\mathrm{raw}}(I_{AB}^\perp)$ 明显高于负控制，即构成极其锋利的顶刊仲裁发现——证明**2026 年最前沿流模型/GNN 的“非加性残差恢复”实质上主要是全局 PC1 饱和阻尼拟合而非基因对特异性上位性**；若连 Split-half $\mathrm{DRF}_{\mathrm{raw}}(I_{AB}^\perp)$ 也极低（$< 0.20$），则定量证明现有组合 Perturb-seq 数据的测序深度/细胞数在统计功效上尚不足以基准测试高维离轴上位性。两种结果均满足预注册假说检验标准。
