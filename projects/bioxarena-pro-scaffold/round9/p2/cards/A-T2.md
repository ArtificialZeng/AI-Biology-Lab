# A-T2 方法（写 p2/vcc_linespecific/src/ 与 results/）
等 A-T1 交付 Replogle 两条线后开始。开发只用 K562↔RPE1。
实现以下预测器。所有预测器对目标线只能使用其对照细胞和靶点列表：
1. **迁移均值（基线）**：源线响应的平均。
2. **CIPHER 式线性响应**：用目标线对照细胞的协方差 C_t，预测 Δ ≈ λ · C_t[:, g] / C_t[g, g] 的形式（按 CIPHER v2 方法部分核对公式，引用准确）。λ 只在源线上拟合。
3. **混合**：共享部分取迁移均值；线特异部分取 (C_t 预测 − C_s 预测) 在源线平均上的差，并可投影掉共享轴（参考本项目 v5 / PC1 分解）。不得调目标线上的任何参数。
4. **阴性对照**：用错配细胞系的协方差；用打乱基因标签的协方差。
同时实现评测：Arc 线特异斜率（定义以 A-T5 交付的官方定义为准）、行级配对 bootstrap CI、本项目已有的 DRF 校准指标（disc_raw、de50_r）。
**在 PREREG_COMMIT.txt 出现前，不得在 Replogle 以外的线上跑评测。** 出现之后，按预注册跑全部留一细胞系，结果写 `results/`，含 CSV 与 summary JSON。
