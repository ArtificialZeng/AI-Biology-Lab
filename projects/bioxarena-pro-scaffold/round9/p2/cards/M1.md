# M1 数学：星形图中性 Moran 一致时间精确公式（写 p2/math_moran/）

任务：
1. 核对原文的定义（n 与 N 的关系、初始条件为全员不同类型、时间单位）。
2. 查新：确认至今无人证明（arXiv、OpenAlex 施引文献）。
3. 给出完整证明。可以用中性对偶（合并随机游走）把状态压缩到「叶上谱系数 k、中心是否有谱系」，写出递推并精确求解。
4. 双独立检查器：一个精确有理数求解小 n 的马尔可夫链；一个独立推导或蒙特卡洛。再放一个故意改坏的对照，确认检查器能抓到错误。
5. 若猜想为假，给出精确反例和正确公式。death-birth 情形有余力也做。
