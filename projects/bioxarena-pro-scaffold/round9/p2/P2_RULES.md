## 主控核验后的选题结论
- **主攻（A 队，5 个智能体）**：零样本预测「细胞系特异」的扰动响应。
  - Arc Virtual Cell Challenge 2026 结项报告（2026-11-19）原话：现有模型只恢复了跨细胞系平均，细胞系特异的部分 "remains largely missing"（线特异斜率 0.02–0.13，重复样本为 1.02）。
  - Kawsar 等（bioRxiv 10.64898/2026.11.15.766815，2026-11-17）：不做目标系筛选时，CASTER 低于迁移均值。
  - 最接近的在先工作是 CIPHER（Kuznets-Speck 等，bioRxiv 10.1101/2025.06.27.661814 v2，2026-09-03）：用未扰动细胞的基因共波动（线性响应理论）预测扰动响应。但它没有在「跨系共享 + 线特异残差」分解下检验。
  - 我们的问题：**目标细胞系自己的共波动结构，能不能恢复 VCC 2026 模型漏掉的线特异部分？** 成立或不成立都要如实报告。

  - A1：同厂商与跨厂商审计 2×2 对照实验的预注册设计，只设计不调用付费 API；

## 硬性规则（违反任何一条，结果作废）
1. **文件所有权。** 每个智能体只写自己任务卡列出的目录和 `p2/status/<编号>.txt`。共享输入放在 `p2/shared/`，只有 A-T1 可以写。
2. **不运行 git。** 由主线执行者统一提交。需要提交（例如预注册）时，写 `p2/status/COMMIT_REQUEST_<编号>.txt`，说明要提交哪些文件。
3. **预注册先于评测。** A 队任何智能体在 `p2/prereg/PREREG_A.md` 被 commit 之前，**不得在留出细胞系上计算任何评测指标**（开发只允许用 Replogle K562↔RPE1 这一对）。commit 哈希由主线执行者写进 `p2/status/PREREG_COMMIT.txt`。看到这个文件后才能跑留出评测。
4. **MPS/GPU 锁。** 用 GPU 之前执行 `mkdir p2/locks/mps_<n>`（n=1 或 2），成功才算拿到锁，用完 `rmdir`。全队同一时间最多 2 个 GPU 任务；CPU 任务不限，但单个不超过 12 小时。
5. **下载。** 只下载公开数据，下载前在 `p2/shared/DATA_SOURCES.md` 记录 URL、许可证、大小和 sha256。全队总量不超过 60 GB。**严禁 X-Atlas/Orion 及其衍生数据**；不碰 xatlas 基因身份。
6. **不对外行动。** 不发帖、不开 issue/PR、不发邮件、不注册账号、不接受任何条款、不向任何竞赛提交。需要人类操作的，写进状态文件。
7. **文献与数字。** 文献用 arXiv、bioRxiv、Crossref 或 PubMed API 核实。报告里每个数字都要能追溯到脚本和输出文件。不得写「首次」。
8. **不利结果照写。** 假设不成立时，写「未确认」，不换指标、不换数据补救。

## 状态汇报
每完成一个子任务，把一行状态覆盖写入 `p2/status/<编号>.txt`。全部完成后，末行写 `TASK_DONE`。
