# BioXArena-Pro 科研攻关总纲 (Mission Charter)

## 一、 战略目标与分级标准 (L0 - L4)

在前沿生物医学智能体基准 **BioXArena-Pro** (64 任务，8 大领域) 上开展可复现、统计学显著的科学突破。
（参考背景：22 个前沿配置排行榜最高单项配置 Mean64 = 55.07 [Codex CLI + GPT-6 Astra]；榜单中列出的 57.0 为 22 次运行事后逐任务取最优的拼接值，官方明确标注为 “not a run” 且存在向上偏差，不作为单一系统的目标线。）

严格执行五级成果定级标准：
- **L0**：代码跑通、产物符合格式契约（不具备科研价值）
- **L1**：官方口径下复现基准已公布的参考基线（内部工程基线）
- **L2**：官方口径下在有突破空间的低天花板任务上，多分割均值超过自身复现基线且幅度 > 官方噪声阈值（xatlas 为 0.02）
- **L3**：官方口径下超过排行榜 22 配置最佳分且超出噪声（xatlas 为 10 分割内部均值 ≥ 0.12 或 Codabench 私有 test 实测 > 0.0825），达到对外报道与 workshop 门槛
- **L4**：多任务或 Mean64 层面在 Codabench 实测成立，达到正式学术发表门槛

当前主攻任务：**`perturbation/xatlas-orion-perturb`**（排行榜 22 配置最佳仅 8.25/100，中位数 6.71，是全基准最具科研突破潜力的任务）。

## 二、 科研铁律与红线 (Hard Disciplines D1 - D7)

1. **D1（唯一评分口径）**：100% 调用官方 `tasks/*/grade.py` 或 `tasks/utils.py` 聚合函数，严禁自写截断或非等价指标。
2. **D2（数字可追溯）**：报告与文档中的每一个数字必须对应仓库内可独立运行的脚本与输出，禁止硬编码或无源数字。
3. **D3（严谨消融）**：任何创新点必须在 ≥10 个独立随机分割上报告均值 ± SD 与相对基线增量，并与官方噪声阈值对比；消融测试的模型必须与最终提交的模型完全一致。
4. **D4（格式 ≠ 成绩）**：预检通过仅代表格式合规，不代表模型有效。
5. **D5（安全与数据红线）**：严禁生物安全风险；严禁探测私有标签或使用任何来自原始公开数据集的外部泄漏信息。
6. **D6（文档同步零夸大）**：所有文档与结构化结果表必须如实反映当前定级，严禁在未达标或未经人类 PI 授权前宣称发布就绪。
7. **D7（可比性铁律）**：任何两个数字放在一起比较前，必须明确写出各自的数据集、评分口径、以及推理时是否可得；三项不全同，严禁比较。
