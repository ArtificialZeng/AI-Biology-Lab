## 三、从第一轮至今被彻底撤回或显著降级的说法清单（完整无美化）

### A. 彻底撤回（经核验为虚假、无据、违规或口径错误）
1. **「跨越 Oracle 理论天花板 57.0」**（Round 1, `a8bde5d`）——6 任务公开集内部 CV 与 64 任务官方私有 test 最优拼接均值完全不可比；彻底撤回。
2. **「GDSC 发现全药面板零和守恒并暴拉至 0.1942（+31.2%）」**（Round 1, `a8bde5d`）——零和投影实测为空操作；+31.2% 全由自写 `max(0,r)` 截负产生；官方口径仅 `0.1199`，低于官方基线 `0.148` 及全部 22 配置；彻底撤回。
3. **「DTI 从历史低谷 29.6 分提升至 41.2 分」**（Round 1, `a8bde5d`）——`41.2` 在全仓库无任何代码或输出对应，属凭空编造数字；彻底撤回。
4. **「SLSQP 凸优化融合实测带来 +2.55% 净增益」与「60 秒保底生存引擎首创」**（Round 1, `a8bde5d`）——`ood_ensemble_selector.py` 从未被调用，Tier-1 引擎无代码实现；彻底撤回。
5. **「30-kNN 共表达加权 0.0503 完美对齐 ±0.01」**（Round 2, `fa7165f`）——`0.0503` 为脚本硬编码字面量，无对应代码；彻底撤回并补写实算代码。
6. **「余弦 Ridge 0.0804 平视排行榜 SOTA 0.0825，达到 L2」**（Round 2, `fa7165f`）——seed 42 为 10 分割最幸运抽样，真实 10 分割均值增量仅 `+0.0031`（不足 0.02 噪声阈值 16%），且跨集对比无效；退回 L1。
7. **「同靶点跨系残差相关性 0.2267 远高于全网 SOTA 0.0825」**（Round 3, `710e250`）——既无计算脚本，又将推理时覆盖率为 `0/455` 的不可得真值拿去和预测分比；彻底撤回。
8. **「在 xatlas 上做 CORUM / STRING / DepMap 基因身份与疾病靶点验证」**（Round 4, `c479bc6`）——违反 BioXArena 禁止反匿名及使用 Orion 源数据的硬红线；彻底取消。
9. **「5 个 / 10 个从未触碰（untouched）的独立留出分割」与「配对 $t$ 检验 $p = 3.63\times 10^{-8}$ / $1.09\times 10^{-17}$」**（Rounds 4–5, `c479bc6` / `a9ab830`）——切分靶点重叠 62%–70%、训练集重叠 ~80%，独立性假设完全不成立；永久废止并改用 4,000 次行级配对自助法 95% CI。
10. **「内部 ≈ 测试 +0.010，预期 Codabench 0.092–0.100+」**（Round 4, `c479bc6`）——官方 `0.051` 为公开训练集单个 fold 而非私有 test，换算无依据；彻底撤回。
11. **「Reactome 全基因组背景富集 FDR $4.4\times 10^{-16}$ 还原中介体复合物验证机理」**（Round 5, `a9ab830`）——S0 基线同等规模集合富集更高，中介体亚基数为 0，全基因组背景虚高；彻底撤回，改为 GMT 注释评测全集（1,452）上 `S7 − S0` / `S5 − S2` 增益集富集 + 50 次随机对照。
12. **「AI 系统列为论文作者」**（Round 7, `cb3935f`）——违反 ICMJE 及 *Nature*/*Science*/*Cell* 署名政策；撤回，改为人类署名 `[Human PI]` + Methods AI 使用声明。
13. **「指标选择导致排名反转是本文新发现」**（Round 8, `9077d8d`）——Miller et al. (*Nature Biotechnology* 2026) 与 arXiv:2604.27646 已先行发表；彻底撤回原创宣称，改写为在先驱工作基础上的预注册三数据集确认 + PC1 轴分解 + 可迁移跨系核与正交融合。

### B. 显著降级或加严限定（保留核心事实但收缩边界）
1. **「打破 Nature Methods 线性壁垒 / 四支柱全面击败」**（Round 5, `a9ab830`）→ 降级为「在扰动特异指标（`v5`、`disc_raw`）上优于线性基线，在传统 `delta_r` / `de50_r` / `de50_sign` 上显著落后线性基线」。
2. **「谱剥离金字塔（S2）与互惠因果律（S6）为核心通用突破」**（Round 5, `a9ab830`）→ 降级为「外部可迁移核心为 `S1`（HybridTOM 核）与 `S5`（跨系桥接）；`S6`（改称 Reciprocal Response Borrowing）在 Replogle `v5` 上为负贡献且在匿名 xatlas 上无法排除 CRISPRi 顺式邻近混杂」。
3. **「甩开 GPT-6 / Claude 等 22 个 Agent 配置」**（Rounds 4–7）→ 降级为「Codabench 私有测试集 `0.0998` 比最佳 2 小时自主 agent（`0.0825`）高 `+0.0173`（在 `0.02` 噪声阈值内），且属多轮人机协作迭代，与单次 2 小时自主 agent 不属同一比较类别」。
4. **「击败深度模型 GEARS / scGPT」**（Rounds 5 & 7）→ 降级为「(a) 自制网络标为 `Simplified_GNN`/`ResMLP`；(b) 第七轮官方包标为 `GEARS (official package, pseudobulk-adapted)`（非原生单细胞，另行开展 R8-1 原生单细胞评测）；(c) 相对最强基线 `scGPT_FrozenEmb_Ridge`，零预训练 `S5` 仅在 `v5` 胜出，在 `disc_raw` 打平，在 `delta_r` 显著落后」。
5. **「Replogle `LOO_S6`（0.1512）作为最优主方法」**（Round 6, `3609811`）→ 降级为探索性变体，第七轮预注册严格锁定 `S5` 为主方法。
6. **「Reactome 富集用 1,784 全集背景」**（Round 7, `cb3935f`）→ 降级为补充敏感性结果，主文改用更严格的 GMT 注释背景（1,452：剪接 FDR `2.90e-08`，线粒体翻译 FDR `6.98e-03`）。
